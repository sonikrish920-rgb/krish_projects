# 📝 Personal Notes

![HTML5](https://img.shields.io/badge/HTML5-page-E34F26?style=flat-square&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-responsive-1572B6?style=flat-square&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-local_storage-F7DF1E?style=flat-square&logo=javascript&logoColor=black)

A small notes app that lets you create and delete notes saved in the current browser's local storage. Notes are not synced to a server and are available only in the same browser profile.

## 🚀 Run

Open `index.html` in a modern browser. If the browser blocks local storage for local files, serve this folder using any static HTTP server.

## 📁 Files

| File | Purpose |
|---|---|
| `index.html` | App structure and note form |
| `style.css` | Responsive layout |
| `note.js` | Safe note rendering and local storage |
