A responsive login and account-creation interface with browser-side required-field checks and password confirmation. This is a front-end demo only: it has no authentication backend and never sends or stores credentials.

## 🚀 Run

Open `index.html` in a modern browser. The Poppins typeface is fetched from Google Fonts; the system sans-serif font is used if the request is unavailable.

## 📁 Files

| File | Purpose |
|---|---|
| `index.html` | Login and signup forms |
| `style.css` | Layout and form styles |
| `script.js` | Form switching and demo-only validation |
