# Calculator

A responsive four-function calculator with decimal input, sign toggle, delete, clear, and keyboard support. Operations are evaluated in the order entered.

## Run

Open `calculator.html` in a modern browser. Use the on-screen buttons or the keyboard (`0`–`9`, `.`, `+`, `-`, `*`, `/`, Enter, Backspace, and Escape).

## Files

- `calculator.html` — calculator controls
- `cal.css` — layout and button styles
- `calculator.js` — input and arithmetic logic
