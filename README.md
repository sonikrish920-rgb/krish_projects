## 🧭 Projects

| # | Project | What it does |
|---:|---|---|
| 1 | [Random Joke Generator](./project%201/README.md) | Fetches a joke from JokeAPI. |

## 🚀 Run

Open the relevant HTML file in a modern browser. Some projects use external services (JokeAPI, Tenor, Google Fonts, or the jQuery CDN) and require internet access. See each project README for its exact entry point and dependencies.
