A responsive Diwali greeting page with a local background image and optional music playback.

## 🚀 Run

Open `diwalispecial.html` in a modern browser. Keep `dimg.jpg` and `daudio.mp3` alongside the HTML file. Music starts only after the user presses Play.

## 📁 Files

| File | Purpose |
|---|---|
| `diwalispecial.html` | Greeting, layout, and audio controls |
| `dimg.jpg` | Background image |
| `daudio.mp3` | Optional music track |
