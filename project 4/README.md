A playful multi-page proposal with Yes and No choices. Selecting No moves through increasingly persuasive pages; the last No button moves around the viewport.

## 🚀 Run

Open `index.html` in a modern browser. The animated Tenor stickers are loaded from an external service and require internet access; the text and navigation remain available if that service is unavailable.

## 📁 Files

| File | Purpose |
|---|---|
| `index.html` | Opening question |
| `no1.html`, `no2.html`, `no3.html` | Follow-up pages |
| `yes.html` | Yes response |
| `style.css` | Shared layout |
| `script.js` | Final playful No button behavior |
