A small responsive page that fetches one safe, single-part joke at a time from the public [JokeAPI](https://v2.jokeapi.dev/).

## 🚀 Run

Open `jokes.html` in a modern browser. An internet connection is required for jokes to load.

## 📁 Files

| File | Purpose |
|---|---|
| `jokes.html` | Page structure |
| `style.css` | Presentation and responsive layout |
| `script.js` | API request, loading state, and error handling |
