# 🤔 Decision Helper

![HTML5](https://img.shields.io/badge/HTML5-form-E34F26?style=flat-square&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-responsive-1572B6?style=flat-square&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-scoring-F7DF1E?style=flat-square&logo=javascript&logoColor=black)

A browser-only decision tool that compares two named options across three equally weighted criteria: cost, time, and personal preference. It reports the higher score or a tie; it does not decide for you.

## 🚀 Run

Open `index.html` in a modern browser. No build step or server is required.

## 📁 Files

| File | Purpose |
|---|---|
| `index.html` | Decision form and scoring questions |
| `style.css` | Responsive layout |
| `script.js` | Input validation and score calculation |
